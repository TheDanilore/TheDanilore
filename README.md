## 🚀 Ecosistemas y Proyectos Core

### ✂️ BarberTrack PRO (ERP/CRM & PWA VIP)
Solución empresarial para salones de alta gama estructurada bajo **Clean Architecture**.
* **Stack:** Angular 19+ (Signals, Standalone Components), TypeScript 5.x, Supabase, Vanilla CSS.
* **Features:** Módulo Power User para administradores (caja atómica en Postgres, agenda en tiempo real) y un **Portal VIP Mobile-First** para clientes con tarjeta "Black Card" virtual, Web APIs (vibración háptica) y sistema de diseño adaptativo (Glassmorphism).

### 📦 Inventory Store App (ERP & E-Commerce Omnicanal)
Solución multiplataforma con despliegue en **Web y Mobile** desde una base de código única.
* **Stack:** Flutter (Dart), BLoC / Cubit, Injectable / GetIt, Supabase (Auth, RLS, Realtime), Redis, Docker.
* **Features:** Clean Architecture estricta, control de stock multialmacén, carrito asíncrono y blindaje de datos sensibles directamente desde la aplicación mediante políticas RLS en base de datos.

### 🤖 ChurnInsight - Predicción de Churn & Microservicios
Arquitectura Monorepo orquestada en contenedores para análisis predictivo.
* **Stack:** Java 21 (Spring Boot), Python 3.13 (FastAPI), Vue.js 3 + Vite, PostgreSQL 15, Redis Alpine, Docker.
* **Features:** Núcleo transaccional en Spring Boot conectado de forma asíncrona a un microservicio en FastAPI dedicado exclusivamente al procesamiento de Machine Learning para anticipar la cancelación de clientes.
